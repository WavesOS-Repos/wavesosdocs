# Theme Installation

**Repository:** WavesHyprland  
**Branch:** main (WavesOS current)
**Version:** 0.1.0

---


## Script

scripts/install_themes.sh

## Role

Installs theme packs from the repository themes/ directory into appropriate system or user theme locations (GTK, icons, Plasma-related Relax themes, etc.).

Exact destination paths and helper commands are implemented in the script body. Review the script before modifying theme layout.

## Related

Relax GTK theming expectations are documented in the project README rules. Icon and cursor themes may also be affected by nwg-look / qt6ct configuration deployed under configs/.

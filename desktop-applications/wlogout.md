# wlogout

**Config:** `~/.config/wlogout/` (`layout`, `style-dark.css`, `style-light.css`)  
**Launcher:** `~/.config/hypr/scripts/wlogout.sh` or `launch-wlogout.sh`

---

## Significance

Graphical power menu (lock, logout, reboot, shutdown, etc.) consistent with dark/light and optional Matugen-linked colours.

---

## Integration notes

- Styles can import or mirror Waybar/Matugen colour variables.  
- Launch from keybind (often Super+X).  
- Theme-switch may select dark vs light CSS.

```bash
~/.config/hypr/scripts/wlogout.sh
```

## Source

configs/hypr/configs/programs.lua

Defines default applications used by Hyprland (terminal, file manager, browser, etc.) via the Lua configuration API. Exact assignments should be read from the file when customizing defaults; helper scripts default_browser.sh and default_editor.sh also manage user preference outside pure Hyprland config.
